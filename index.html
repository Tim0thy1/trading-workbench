⚙️ 同步设置

配置 GitHub Token 后，Todo 数据将写回工作台仓库，实现跨设备同步。

建议生成一个只限本仓库的 token：
① GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
② Repository access 选 Only select repositories → 勾选 trading-workbench
③ Permissions → Contents 选 Read and write
④ 生成后粘贴到上方，点保存即可
